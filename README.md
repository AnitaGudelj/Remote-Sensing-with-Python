# Remote-Sensing-with-Python
Jupyter Notebook exercises and supplementary materials for the university textbook Remote Sensing in a Function of Sustainable Development of the Maritime Sector.

## Overview

This repository contains practical exercises, datasets, and example outputs used throughout the textbook. The notebooks demonstrate the application of Python for processing and analysing Earth observation data, with a particular focus on Sentinel-2 imagery and maritime applications.

## Repository Structure

```
Remote-Sensing-with-Python
│
├── Lesson_13
├── Lesson_14
├── README.md
└── LICENSE
```

Each lesson contains:

- Jupyter Notebook exercises (`.ipynb`)
- input datasets
- output examples
- lesson-specific documentation

## Software Requirements

The exercises were developed using:

- Python 3.12+
- Jupyter Notebook
- NumPy
- Matplotlib
- Rasterio
- GeoPandas
- Contextily
- Shapely

Required packages can be installed using:

```bash
pip install numpy matplotlib rasterio geopandas contextily shapely
```
